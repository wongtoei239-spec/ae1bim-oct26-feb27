# Vet-Entregas-Clínicas

Proyecto desarrollado para la asignatura **Desarrollo Basado en Plataformas Web**, con el objetivo de poner en práctica la creación de bases de datos, relaciones entre entidades y consultas utilizando **Python, SQLite y SQLAlchemy**.

# ¿Cómo ejecutarlo?

Primero, instalar SQLAlchemy:

`pip install SQLAlchemy`

Luego, ejecutar los archivos en este orden:

1. `crear_base_entidades.py` — Crear las tablas
2. `poblar_base.py` — Registrar los datos
3. `consulta_all.py`, `consulta_filter.py`, `consulta_order_by.py`, `consulta_or.py` y `consulta_and.py` — Realizar las consultas

Los datos utilizados son ficticios y tienen fines académicos.
